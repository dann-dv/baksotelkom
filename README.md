# 🍲 Bakso Telkom — Landing Page

Project landing page for Bakso Telkom, built with Next.js, Tailwind CSS, and Three.js.

GitHub connection test - commit check untuk memastikan folder project ini terhubung ke repositori GitHub.

Landing page premium untuk usaha kuliner **Bakso Telkom Klaten**. Dibangun dengan desain elegan, minimalis, dan dilengkapi elemen 3D interaktif.

## ✨ Fitur

- **Model 3D Interaktif** — Mangkuk bakso 3D yang berputar dan mengikuti kursor (Three.js + React Three Fiber)
- **Animasi Halus** — Transisi antar section dengan Framer Motion
- **Scroll Horizontal Menu** — Carousel menu dengan dukungan swipe/drag
- **Responsif** — Mobile-first design (HP, Tablet, Desktop)
- **CTA WhatsApp** — Tombol pesan langsung ke WhatsApp pemilik
- **Google Maps Embed** — Integrasi peta lokasi warung
- **Skeleton Loading** — Placeholder loading yang mulus
- **Security Headers** — CSP, HSTS, X-Frame-Options

## 🛠 Tech Stack

| Teknologi                                                                       | Kegunaan                          |
| ------------------------------------------------------------------------------- | --------------------------------- |
| [Next.js 16](https://nextjs.org)                                                | Framework React dengan App Router |
| [Tailwind CSS v4](https://tailwindcss.com)                                      | Utility-first CSS                 |
| [Three.js](https://threejs.org) + [React Three Fiber](https://r3f.docs.pmnd.rs) | Elemen 3D interaktif              |
| [Framer Motion](https://motion.dev)                                             | Animasi & transisi                |
| [Lucide React](https://lucide.dev)                                              | Ikon                              |
| TypeScript                                                                      | Type safety                       |

## 📁 Struktur Halaman

1. **Hero Section** — Headline + CTA + Model 3D bakso interaktif
2. **Tentang** — Cerita & keunggulan (foto warung asli)
3. **Menu** — Carousel horizontal daftar menu & harga
4. **Info & Lokasi** — Jam operasional + Google Maps
5. **Footer** — Logo, kontak WhatsApp, hak cipta

## 🚀 Menjalankan Lokal

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
